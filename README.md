# Codeforge
A browser-based IDE for web and Python projects — like CodePen, but with real project management, local storage, and Python support built right in.

•	Full project management with templates, not just single snippets
	•	Python runs directly in the browser via Pyodide (WASM) — including interactive input() support
	•	Fully offline-capable, single-file architecture
	•	Command palette, custom modals, and search/replace built into the editor
	•	Export projects as ZIP or JSON for backup and sharing

Built with: CodeMirror 5 for syntax highlighting, Pyodide for in-browser Python execution, JSZip for exports, and js-beautify for code formatting — all running entirely client-side, with no backend server required.

Whether you’re prototyping a quick script, building a small web app, or just want a persistent coding sandbox without setting up a local dev environment, CodeForge-IDE keeps everything in one place.
